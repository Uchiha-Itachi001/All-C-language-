## 🚀 Getting Started

```sh
git clone https://github.com/Uchiha-Itachi001/All-C-language-.git
```

- **Browse** the folders to find the topic or program you need.
- **Compile and run** any `.c` file using your favorite C compiler:
  ```sh
  gcc filename.c -o filename
  ./filename
  ```
